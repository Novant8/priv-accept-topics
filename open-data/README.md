# Open Data

Here, we offer the datasets we used in the paper, as well as the plots and the code for creating the plots.

The datasets include a compact CSV version of the crawler's outputs, and the collection of total, *Allowed* and *Attested* domains encountered.

The code to generate the plots are inside Python Jupyter notebooks. The notebooks are verified to work using Python version 3.13.9 and install the needed dependencies automatically.

## Folder structure

- Notebooks
  - [`longitudinal-plots.ipynb`](longitudinal-plots.ipynb): generates the longitudinal measurements and figures. **Note:** this notebook is time- and memory-intensive. On our machine it took about one hour to run and required approximately 32 GB of RAM.
  - [`firefox-vs-chrome-plots.ipynb`](firefox-vs-chrome-plots.ipynb): compares two snapshots taken on the same day (Firefox vs Chrome).

- Outputs
  - [`outputs-longitudinal/`](outputs-longitudinal/): archive of crawl outputs. See [`outputs-longitudinal/README.md`](outputs-longitudinal/README.md) for details about the zip contents.
  - [`outputs-firefox-vs-chrome/`](outputs-firefox-vs-chrome/): crawler outputs of the two snapshots collected using Chrome and Firefox. They follow the same structure as those included in `outputs-longitudinal`.
  - Compact CSVs and other derived datasets used by the notebooks are stored inside the `outputs-longitudinal` zips referenced above.

- Plots
  - Plots generated by the `longitudinal-plots.ipynb` and `firefox-vs-chrome-plots.ipynb` are saved in [`plots-longitudinal/`](plots-longitudinal/) and [`plots-firefox-vs-chrome/`](plots-firefox-vs-chrome/), respectively.

- Additional data files
  - [`domain_map.json`](domain_map.json) — domain-to-entity mapping used by the notebooks to resolve domain ownership / display names. Credit to [DuckDuckGo's tracker radar](https://github.com/duckduckgo/tracker-radar/blob/main/build-data/generated/domain_map.json).
